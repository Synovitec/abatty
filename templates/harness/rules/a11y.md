# Accessibility rules (loaded when markup, styles or the theme are open)

Depth, the legal frame and the numbers: the standard's `guides/A11Y.md` (shipped under `docs/standard/` of the package). Target: WCAG 2.2
AA (EN 301 549); the European Accessibility Act applies to e-commerce sold to EU consumers.

- Native element before ARIA. A `div` or `Box` with `onClick` is not a control: `button`,
  `IconButton`, `ListItemButton`, `a href`. No ARIA that a native element already provides; no
  `role="presentation"` or `aria-hidden` on a focusable element; no positive `tabindex`.
- `<html lang>` and `dir` from the locale; one `h1` per page; no skipped heading level; one
  `main`; a working skip link (never hidden with `display: none`).
- Every field has a real label (`TextField label`, or `InputLabel` linked by id) and standard
  `autocomplete`; errors are announced (`role="alert"` or a live region) and linked from a
  summary. A placeholder is not a label.
- Every icon-only control has an accessible name; with `asChild` it goes on the child that
  renders. Decorative images `alt=""`; an image in a link gets the link's text as alt.
- Focus ring kept and never obscured by a sticky header (2.4.11); modals trap and restore focus
  and close on Escape; focus moved to the `h1` or `main` on a client-side route change, and
  the new title announced in a live region.
- Contrast 4.5:1 for text, 3:1 for large text and non-text UI (1.4.11), in both themes,
  computed from the token file by a script. Colour is never the only carrier of information;
  a tooltip is never the only carrier either.
- Targets 24x24 CSS px minimum (2.5.8), 44px on phone surfaces; text inputs 16px on touch.
- `prefers-reduced-motion` honoured; scroll-reveal content visible by default with the animation
  added on top; nothing auto-moving for more than 5 seconds without a control.
- Nothing asked twice in one flow (3.3.7); authentication never a memory test: a password or
  TOTP field accepts paste and a password manager (3.3.8); a drag has a single-pointer
  alternative (2.5.7).
- `eslint-plugin-jsx-a11y` at error, with `settings['jsx-a11y'].components` mapping the
  library's primitives AND `polymorphicPropName` set - without both it reports zero on code
  that fails. `axe` in the browser suite on the critical journeys, blocking.
- A public accessibility statement page names the target, the known gaps and a contact.
